منصة فرسان العلوم — نسخة جاهزة للنشر (المرحلة الأولى)

الملفات:
1) index.html
   واجهة الطلاب. لا تحتوي على زر لوحة التحكم الظاهر ولا نافذة الإدارة.
2) admin.html
   نسخة الإدارة. تفتح شاشة دخول لوحة التحكم تلقائياً.
3) SECURITY-README.txt
   هذا الملف.

مهم جداً:
- فصل admin.html عن index.html يمنع المستخدم العادي من رؤية لوحة الإدارة في الواجهة،
  لكنه ليس حماية نهائية وحده إذا كانت بيانات الدخول أو الصلاحيات مخزنة داخل JavaScript.
- الحماية الحقيقية تحتاج مصادقة من الخادم وقاعدة بيانات، مثل Supabase أو Firebase،
  مع سياسات صلاحيات تمنع الطالب من تعديل البيانات.
- لا ترسل ملفات HTML للطلاب. انشر المجلد على استضافة، وأرسل رابط index.html فقط.
- لا تضع اسم المستخدم وكلمة المرور الحقيقيةين كنص ثابت داخل JavaScript في النسخة النهائية.
- بعد ربط قاعدة البيانات، اجعل admin.html محمياً بجلسة دخول حقيقية، والطلاب بصلاحية قراءة/حل فقط.

خطوة النشر المقترحة:
- ارفع index.html و admin.html إلى مستودع GitHub خاص.
- انشر واجهة الطلاب على خدمة استضافة.
- اجعل رابط admin.html معروفاً لك فقط مؤقتاً.
- في المرحلة التالية اربط تسجيل الدخول والنتائج وقوائم الطلاب بقاعدة بيانات حقيقية.
